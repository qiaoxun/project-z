# 围棋课堂（web-go）

局域网围棋教学系统：一个老师端 + 多个学生端实时同步。基于原单机版 `go-game.html` 的规则与视觉开发。
零依赖 NodeJS（HTTP + SSE），所有状态存于服务端内存，任何端刷新/断线重连后都会自动恢复。

## 启动

```bash
node server.js [老师口令] [端口]
# 例：node server.js 123456 3000
# 默认口令 123456，默认端口 3000
```

启动后控制台会打印本机与局域网地址，学生用浏览器访问局域网地址即可。

## 使用

- 入口页：`http://<老师电脑IP>:<端口>/`（可选老师端 / 学生端）
- 老师端：`http://<老师电脑IP>:<端口>/teacher`（输入口令登录，浏览器会记住）
- 学生端：`http://<老师电脑IP>:<端口>/student`（首次填写名字，不允许重名；刷新/断线自动恢复身份）
- 同一浏览器开多个标签页即可模拟多名学生

## 三种模式

| 模式 | 老师端 | 学生端 |
| --- | --- | --- |
| 教学 | 自由落子演示，默认围棋规则（黑白自动轮流），可切「自由摆子」（忽略规则、可连下同色并选颜色）；支持上一步/下一步、停一手、清空 | 只读，实时同步老师棋盘 |
| 对战 | 选择在线学生 + 执黑/执白开始；强制完整规则，只有轮到的一方可落子；老师有「悔棋」；无胜负判定 | 被选中的学生对弈（轮到自己才能落子），其余学生观战 |
| 学习 | 摆棋阶段学生端只显示「老师正在出题」；点「开始练习」下发棋谱，可重新下发或结束 | 收到棋谱后本地自由操作（完整规则、黑白自动轮流），可悔棋、回到初始棋谱；操作仅本机显示，不同步回老师端 |

其它：棋盘 9×9 / 13×13 / 19×19 随时切换（会清空棋盘并同步所有人）；界面默认中文，右上角可切英文（各自记住）。

## 文件

- `server.js` —— 服务端（HTTP 静态 + SSE 推送 + `/api/*` 操作，内存状态）
- `public/go-engine.js` —— 围棋引擎（服务端与浏览器共用 UMD）
- `public/common.js` —— 前端共用库（i18n / 请求 / SSE / 棋盘渲染）
- `public/index.html` / `teacher.html` / `student.html` —— 入口页 / 老师端 / 学生端
- `go-game.html` —— 原始单机版，保留作参考
