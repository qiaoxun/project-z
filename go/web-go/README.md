# 围棋课堂（web-go）

局域网围棋教学系统：一个老师端 + 多个学生端实时同步。基于原单机版 `go-game.html` 的规则与视觉开发。
零依赖 NodeJS（HTTP + SSE），所有状态存于服务端内存，任何端刷新/断线重连后都会自动恢复。

## 启动

```bash
node server.js [老师口令] [端口]
# 例：node server.js 123456 3000
# 默认口令 123456，默认端口 3000
```

启动后控制台会打印本机与局域网地址，学生用浏览器访问局域网地址即可。

## 使用

- 入口页：`http://<老师电脑IP>:<端口>/`（可选老师端 / 学生端）
- 老师端：`http://<老师电脑IP>:<端口>/teacher`（输入口令登录，浏览器会记住）
- 学生端：`http://<老师电脑IP>:<端口>/student`（首次填写名字，不允许重名；刷新/断线自动恢复身份）
- 同一浏览器开多个标签页即可模拟多名学生

## 三种模式

| 模式 | 老师端 | 学生端 |
| --- | --- | --- |
| 教学 | 自由落子演示，默认围棋规则（黑白自动轮流），可切「自由摆子」（忽略规则、可连下同色并选颜色）；支持上一步/下一步、停一手、清空 | 只读，实时同步老师棋盘 |
| 对战 | 选择在线学生 + 执黑/执白开始；强制完整规则，只有轮到的一方可落子；老师有「悔棋」；无胜负判定 | 被选中的学生对弈（轮到自己才能落子），其余学生观战 |
| 学习 | 摆棋阶段学生端只显示「老师正在出题」；点「开始练习」下发棋谱，可重新下发或结束；棋局带正解时自动判题（见下） | 收到棋谱后本地自由操作（完整规则、黑白自动轮流），可悔棋、回到初始棋谱；操作仅本机显示，不同步回老师端 |

其它：棋盘 9×9 / 13×13 / 19×19 随时切换（会清空棋盘并同步所有人）；界面默认中文，右上角可切英文（各自记住）；学生端有「数气」标注工具——点击进入数气模式后，在棋盘上每点一下盖一个递增数字（1、2、3…，点已有数字的点可删除），用于自己数气；纯本地显示，不影响棋局，棋盘变化时自动清除。

## 导入外部棋谱（101围棋网等）

老师端摆棋工具箱里有「导入棋谱」按钮，支持标准 SGF。针对需要登录的网站（如 101围棋网）提供书签工具：

1. 老师端点「导入棋谱」，把弹窗里的 **📌 复制棋谱** 链接拖到浏览器书签栏（或点「复制书签代码」后手动新建书签）
2. 在自己已登录的 101围棋网题目/棋谱页面，点书签栏里的「复制棋谱」——页面内嵌的 SGF 会复制到剪贴板
3. 回到老师端「导入棋谱」粘贴，点「导入到棋盘」

导入说明：自动识别棋盘路数并切换；`AB/AW` 摆子与主线着手都会摆上；主线黑白交替时按真实规则落子（提子/打劫生效），同色连下（习题常见）按自由摆处理；导入的着手保留历史，可用「上一步/下一步」回放；在学习模式导入后点「开始练习」即可发给学生。注意：101围棋网的书页需登录才能看到，请务必在自己已登录的浏览器里使用书签工具；直接粘贴 SGF 文本也支持。

## 题库与自动判题

老师端摆棋工具箱有「题库」按钮：

- **存题**：摆好棋局（或导入棋谱）后，在题库弹窗里填名称、分类（死活/手筋/定式/官子…），点「存入题库」。当前棋局带正解时会标注「正解判定」。
- **用题**：列表里点「摆到棋盘」即可复现局面；学习模式下也可点「从题库选题」，选完直接「开始练习」下发。
- 题目保存在服务端 `data/problems.json`，重启不丢；可按分类筛选，可删除。

**自动判题**（正解来自导入的带分支 SGF，如 101围棋网死活题）：

- 导入成功后提示「含 N 条正解」；正解的取法：若 SGF 注释里标了 `C[RIGHT]`/`C[正解]`（goproblems 等题库惯例），只认标记线；否则把首个着手处的**第一个分支**当正解，同层其余分支当备选正解。更深层的变化分支视为对手的备选应手，不参与判题。
- 点「开始练习」后，正解随棋谱发到学生端（仅练习进行中下发）：学生走出题方的棋，每步与正解比对——**下错立即提示「再想想」且不落子**；下对则对方应手由本地按正解自动补上（含提子）。走完全部正解着法即「🎉 答对了」，棋盘锁定，等老师出下一题或学生自己点「回到初始棋谱」重做。悔棋会连同自动应手一起回退。
- 没有正解的题目（手工摆的局、整盘棋谱）照旧自由练习。注意：练习期间正解数据会随状态发给所有端，学生用浏览器开发者工具理论上能看到，教学场景通常无妨。

## 文件

- `server.js` —— 服务端（HTTP 静态 + SSE 推送 + `/api/*` 操作 + SGF 树解析/正解提取 + 题库持久化）
- `public/go-engine.js` —— 围棋引擎（服务端与浏览器共用 UMD）
- `public/common.js` —— 前端共用库（i18n / 请求 / SSE / 棋盘渲染 / 正解判题器）
- `public/index.html` / `teacher.html` / `student.html` —— 入口页 / 老师端 / 学生端
- `public/style.css` —— 样式
- `data/problems.json` —— 题库（运行时生成，不入库）
- `go-game.html` —— 原始单机版，保留作参考
